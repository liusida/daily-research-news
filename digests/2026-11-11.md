# Research digest — 2026-11-11

## Top picks

### Making visual features clearer
This work changes visual features inside a model and shows the effect in images. The images helped distinguish feature meanings across several vision models and datasets.

[arXiv](https://arxiv.org/abs/2611.05522) <a class="likes" href="https://www.alphaxiv.org/abs/2611.05522" title="likes on alphaXiv">♥ 10</a>

### Finding robot failures inside a model
This work uses signals inside a robot model to predict failures. On tasks the model had not seen, it identified failure types better than a simple baseline.

[arXiv](https://arxiv.org/abs/2611.08425) <a class="likes" href="https://www.alphaxiv.org/abs/2611.08425" title="likes on alphaXiv">♥ 14</a>

### Finding ads in model replies
This work controls how prominent ads are in model replies and uses attention to find them. Its ad labels were more accurate than those of the other methods tested.

[arXiv](https://arxiv.org/abs/2611.00822) <a class="likes" href="https://www.alphaxiv.org/abs/2611.00822" title="likes on alphaXiv">♥ 10</a>

### Testing models on network weights
This post tests Claude Fable 5.2 on tasks involving neural network weights. It named the game a policy was trained on from its weights, matching GPT-6 Astra on that task.
