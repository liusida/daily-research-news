# Research digest — 2026-11-09

## Top picks

### Hidden coordination between agents

Researchers study signs of hidden cooperation inside language model agents. In a card-counting task, they found a hidden count inside the receiving agent and changed it.

[arXiv](https://arxiv.org/abs/2611.02153) <a class="likes" href="https://www.alphaxiv.org/abs/2611.02153" title="likes on alphaXiv">♥ 13</a>

### Shared features and attacks on vision models

This work checks an earlier claim that shared model space can help explain attacks on vision models. Across the datasets tested, more feature sharing went with attacks that more closely matched the layout of the model’s class representations.

[LessWrong](https://www.lesswrong.com/posts/TRe3CxDirbjPC7bQg/confirming-claims-of-superposition-and-adversarial-examples-1) <span class="likes" title="karma on LessWrong">▲ 8</span>

### Steering models against prompt injection

Researchers tested a way to find and steer model representations of tool use. It helped in some tests, but did not show a general advantage across models and datasets.

[LessWrong](https://www.lesswrong.com/posts/27aBj6HA8JyBzDAcv/trying-to-steer-pi-with-prefix-label-directions) <span class="likes" title="karma on LessWrong">▲ 1</span>

### How code models represent risk

Researchers studied how code models represent security risks. The models’ internal representations made it easier to tell which of two code samples was riskier than to label each sample on its own.

[arXiv](https://arxiv.org/abs/2610.27257) <a class="likes" href="https://www.alphaxiv.org/abs/2610.27257" title="likes on alphaXiv">♥ 10</a>

### Reading a model’s weights

Researchers tested whether language models can tell what game another model was trained to play by looking at its weights. One model remained accurate using only part of the weights, while another relied heavily on labels in the prompt.

[LessWrong](https://www.lesswrong.com/posts/WnL4nWrS2owzZfwiz/what-do-llms-really-learn-about-model-weights-a) <span class="likes" title="karma on LessWrong">▲ 4</span>

### Motion information inside 3D models

Researchers looked for motion information inside 3D models that were not trained further. They could read out which parts were moving and which were still.

[arXiv](https://arxiv.org/abs/2610.33802) <a class="likes" href="https://www.alphaxiv.org/abs/2610.33802" title="likes on alphaXiv">♥ 10</a>

### Why retrieval fails in long inputs

This paper studies why models fail to find information in long inputs. In retrieval tests, unrelated filler did little harm, but statements giving a competing answer caused accuracy to fall.

[arXiv](https://arxiv.org/abs/2611.04169) <a class="likes" href="https://www.alphaxiv.org/abs/2611.04169" title="likes on alphaXiv">♥ 11</a>

### Finding objects through attention

Researchers studied how a vision-language model represents the location of an object. The model’s attention gave a clearer signal of the object’s location than another internal representation they tested.

[arXiv](https://arxiv.org/abs/2610.18729) <a class="likes" href="https://www.alphaxiv.org/abs/2610.18729" title="likes on alphaXiv">♥ 10</a>

### How coding agents use code tools

This paper studies how small coding agents use tools to find the code they need to change. The tools helped some models, but agents rarely followed a chain of links through the code.

[arXiv](https://arxiv.org/abs/2610.33958) <a class="likes" href="https://www.alphaxiv.org/abs/2610.33958" title="likes on alphaXiv">♥ 10</a>

### Hiding unwanted behavior

This paper studies a way to reduce unwanted model behavior. It worked on reward hacking, but the authors found that the behavior was hidden rather than removed.

[arXiv](https://arxiv.org/abs/2611.04260) <a class="likes" href="https://www.alphaxiv.org/abs/2611.04260" title="likes on alphaXiv">♥ 10</a>

### Explaining agent behavior

This post proposes training agents to write explanations of model behavior. It sets out a research plan for testing whether these explanations carry across model families.

[LessWrong](https://www.lesswrong.com/posts/fBBDLoxqZZafP3xZB/behavior-theory-building-for-diverse-agents-and-environments) <span class="likes" title="karma on LessWrong">▲ 1</span>
