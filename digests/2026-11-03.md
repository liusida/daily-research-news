# Research digest — 2026-11-03

## Top picks

### SAE attribution graphs depend on cutoff crossings
Attribution graphs for TopK SAEs miss features that cross the top-k cutoff when you ablate something. A graph that also tracks these margin changes has much lower error at the same cost.
[arXiv](https://arxiv.org/abs/2611.00606)

### Two routes for time-based facts
Models answer "which fact is true at this time" through two parallel routes. One resolves the subject using the year. The other has the last token attend to the year directly. Most queries use both.
[arXiv](https://arxiv.org/abs/2611.01945)

### Linear attention builds the query in hybrid models
In hybrid models, linear attention layers build the query that softmax attention then uses for lookup. Swapping this block between two models restored retrieval without any retraining.
[arXiv](https://arxiv.org/abs/2611.01909)

### Agents that automate attribution graph reading
An LLM with tools reads attribution graphs and answers questions about a model. Results are mixed. It beats baselines at finding spurious features, but not at secret elicitation.
[arXiv](https://arxiv.org/abs/2611.00420)

### A direction for caving to user pushback
Sycophancy under pushback has a linear direction only in models of 7B and larger. Ablating it cuts answer reversals by about a quarter. Weak directions do nothing.
[arXiv](https://arxiv.org/abs/2611.02318)

### Chess model plays dumb but still knows
A chess model that imitates weaker players keeps the same chess knowledge inside. Retraining only the output layer recovers strong moves. So low skill is a different use of the same knowledge.
[arXiv](https://arxiv.org/abs/2611.03439)

### RLVR changes little inside
Across training checkpoints of one model, probes for reasoning mistakes stay about the same. The model's knowledge was already there. Only the final answer token changes.
[arXiv](https://arxiv.org/abs/2611.02574)

### Hidden traits move around bans
Banning the tokens that carry a hidden trait does not remove it. The trait moves to another channel. Patching the circuit that writes it cut the transfer in half.
[arXiv](https://arxiv.org/abs/2611.02509)
