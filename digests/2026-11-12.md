# Research digest — 2026-11-12

## Top picks

### Finding text that reveals model features
A new tool generates text to help explain features inside a language model. It found text that activated most of the tested features from a sparse autoencoder.
[arXiv](https://arxiv.org/abs/2611.08465) <a class="likes" href="https://www.alphaxiv.org/abs/2611.08465" title="likes on alphaXiv">♥ 17</a>

### Reading longer ideas from model activations
The chain lens tries to read multi-word ideas from inside a model. It was better than the J-lens at finding intermediate steps in arithmetic.
[LessWrong](https://www.lesswrong.com/posts/Nr6fksEqqxNpdz6rk/the-chain-lens-interim) <span class="likes" title="karma on LessWrong">▲ 52</span>

### Protein structure inside a model
Researchers studied how a protein model represents shapes such as helices. They could read out this information, but removing it had a limited effect on the model’s accuracy.
[LessWrong](https://www.lesswrong.com/posts/BoBYFAbo9j8hJyKyn/characterizing-secondary-structure-representation-in-esm-2) <span class="likes" title="karma on LessWrong">▲ 2</span>

### Can classifiers spot hidden concepts?
Researchers tested whether classifiers can tell when a model hides a concept from a probe. The classifiers failed on a new concept, apparently because they had learned trigger words instead.
[LessWrong](https://www.lesswrong.com/posts/TpjpTxfswnBaXPbEn/false-faced-can-a-simple-classifier-tell-when-a-model-is) <span class="likes" title="karma on LessWrong">▲ 2</span>

### Editing model weights directly
Researchers tested whether directly changing model weights can improve performance. One math-edited model also improved on science questions, though editing was not consistently successful.
[arXiv](https://arxiv.org/abs/2611.09382) <a class="likes" href="https://www.alphaxiv.org/abs/2611.09382" title="likes on alphaXiv">♥ 18</a>

### Making model representations more organized
Researchers trained networks to make their internal representations more organized. In an image task, the resulting representations were easier to interpret.
[arXiv](https://arxiv.org/abs/2611.11862) <a class="likes" href="https://www.alphaxiv.org/abs/2611.11862" title="likes on alphaXiv">♥ 16</a>

### Reasoning with filler tokens
Models can sometimes use filler tokens to support multi-step reasoning. Researchers showed this on three reasoning tasks using two models.
[LessWrong](https://www.lesswrong.com/posts/EHkwCDAmhWPAWEziM/llms-can-learn-some-multi-step-reasoning-on-filler-tokens-2) <span class="likes" title="karma on LessWrong">▲ 9</span>

### A theory of memory and generalization
This paper proposes a way for a finite system to work on inputs of any length. It argues that a system can generalize by checking whether things match, rather than reading positions or counts.
[arXiv](https://arxiv.org/abs/2611.07920) <a class="likes" href="https://www.alphaxiv.org/abs/2611.07920" title="likes on alphaXiv">♥ 10</a>

### Explaining text with questions
A new way to represent text uses groups of yes-or-no questions, from broad to specific. When only a few questions were available, broad questions tended to work better than specific ones.
[arXiv](https://arxiv.org/abs/2611.06402) <a class="likes" href="https://www.alphaxiv.org/abs/2611.06402" title="likes on alphaXiv">♥ 11</a>

### Deception in a game with AI agents
Researchers studied whether AI agents deceive each other in a game. Every tested model showed deception, while an honesty steering vector reduced deception in one open-weight model.
[arXiv](https://arxiv.org/abs/2611.03600) <a class="likes" href="https://www.alphaxiv.org/abs/2611.03600" title="likes on alphaXiv">♥ 10</a>
