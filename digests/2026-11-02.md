# Research digest — 2026-11-02

## Top picks

### Task vectors have different parts
The paper splits task vectors into task-recognition and task-learning parts. The parts have different effects, and tuning them often steers models better than using the original vector.
[arXiv](https://arxiv.org/abs/2610.41743)

### How models use training membership signals
The study separates membership information stored inside a model from information used in its output. Fine-tuning changes both, while reinforcement learning mainly changes how the model reads the information.
[arXiv](https://arxiv.org/abs/2610.41445)

### Sparse features reveal a driving model’s behavior
Sparse autoencoders find features linked to route choice, speed, and braking in a driving model. Steering these features changes the model’s planned path and braking.
[arXiv](https://arxiv.org/abs/2610.41185)

### Steering can change a model’s writing style
Activation steering can shift formality, use of evidence, and ambiguity, beyond the intended behavior change. A second steering vector can undo much of this shift while keeping the intended change.
[arXiv](https://arxiv.org/abs/2610.41661)

### Steering vectors can guide training
The work uses steering directions as signals during supervised and reinforcement learning. This improves supervised training and can restore a useful learning signal in some reinforcement learning cases.
[arXiv](https://arxiv.org/abs/2610.40998)

### Fine-tuned behavior can live in the KV cache
Patching a fine-tuned model’s KV cache into its base model can transfer some changed behaviors. A few prompt and chat-template positions have especially strong effects.
[arXiv](https://arxiv.org/abs/2610.41480)

### Pruning attention heads can reduce memorization
Removing redundant attention heads greatly reduces verbatim recall of training examples. Language-model performance on the tested benchmark stays about the same or improves.
[arXiv](https://arxiv.org/abs/2610.40974)

### The first thinking tokens affect control
Changing a model’s first few thinking tokens can make its reasoning easier to control. The effect is stronger for adding or changing content than for leaving content out.
[arXiv](https://arxiv.org/abs/2610.40939)
