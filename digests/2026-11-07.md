# Research digest — 2026-11-07

## Top picks

### Finding backdoor circuits
This work studies a way to find backdoor circuits in fine-tuned models. In tests, removing the circuits stopped the backdoors without hurting instruction-following performance.

[arXiv](https://arxiv.org/abs/2610.32866) <a class="likes" href="https://www.alphaxiv.org/abs/2610.32866" title="likes on alphaXiv">♥ 18</a>

### How models learn from examples in a prompt
This work traces a circuit that helps models learn from examples in a prompt. In sentence tests, the circuit matched new sentences to examples and copied the right labels.

[arXiv](https://arxiv.org/abs/2611.05344) <a class="likes" href="https://www.alphaxiv.org/abs/2611.05344" title="likes on alphaXiv">♥ 11</a>

### Finding features in robot models
This work looks for useful features inside robot models. In one test, removing a small part of the training data stopped a model from learning how to recover from failure.

[arXiv](https://arxiv.org/abs/2610.20767) <a class="likes" href="https://www.alphaxiv.org/abs/2610.20767" title="likes on alphaXiv">♥ 16</a>

### Are neurons easier to understand?
This post discusses a claim that neurons may be easier to interpret than previously thought. The author finds the idea promising but is unsure about the results for language models.

[LessWrong](https://www.lesswrong.com/posts/p6kaX6LqfTHFqC6r6/takes-on-already-clean) <span class="likes" title="karma on LessWrong">▲ 13</span>

### Using steering signals in training
This work uses steering signals to guide language model training. In one test, this improved a model trained to copy a teacher model's reasoning.

[arXiv](https://arxiv.org/abs/2610.40998) <a class="likes" href="https://www.alphaxiv.org/abs/2610.40998" title="likes on alphaXiv">♥ 11</a>

### Tracing fine-tuned behavior
This work studies where fine-tuned behaviors arise inside language models. In tests, transferring stored information between models could make a base model respond in German or show misaligned behavior.

[arXiv](https://arxiv.org/abs/2610.41480) <a class="likes" href="https://www.alphaxiv.org/abs/2610.41480" title="likes on alphaXiv">♥ 10</a>

### Same explanation, different action
This work studies robot models that explain their actions in words. In driving tests, changes to images caused new crashes while the model's explanation stayed exactly the same.

[arXiv](https://arxiv.org/abs/2611.04166) <a class="likes" href="https://www.alphaxiv.org/abs/2611.04166" title="likes on alphaXiv">♥ 10</a>

### Do prediction errors show physical surprise?
This work asks whether video models' prediction errors reliably show that an event is physically impossible. In one test, impossible events sometimes produced lower errors than possible ones.

[arXiv](https://arxiv.org/abs/2611.01815) <a class="likes" href="https://www.alphaxiv.org/abs/2611.01815" title="likes on alphaXiv">♥ 11</a>

### Models that change their layer order
This work studies models that can change the order of their layers. On Sudoku and maze tasks, the models used different layer orders for different solution strategies.

[arXiv](https://arxiv.org/abs/2611.03526) <a class="likes" href="https://www.alphaxiv.org/abs/2611.03526" title="likes on alphaXiv">♥ 17</a>

### Predictions that explain themselves
This work presents a prediction model whose explanations show what it uses to make each prediction. It beat CatBoost on many classification tests, but scored slightly below TabICLv2 overall.

[arXiv](https://arxiv.org/abs/2610.39506) <a class="likes" href="https://www.alphaxiv.org/abs/2610.39506" title="likes on alphaXiv">♥ 10</a>

### When models say they are being tested
This post revisits why OLMo says it may be under evaluation. Removing such statements from its training data made it less likely to say this, without changing its refusal rate.

[LessWrong](https://www.lesswrong.com/posts/ivKSFzBZwfadTcEfv/revisiting-verbalized-eval-awareness-in-olmo-and-tracing-it-1) <span class="likes" title="karma on LessWrong">▲ 1</span>
